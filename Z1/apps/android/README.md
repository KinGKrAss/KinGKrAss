# Z1 Android App (Jetpack Compose)

Dieses Verzeichnis enthält die Android-Startstruktur für die mobile App.

## Voraussetzungen
- Android Studio (aktuelle Version)
- Android SDK 35+
- JDK 17

## Start
1. Verzeichnis `apps/android` in Android Studio öffnen.
2. Gradle Sync ausführen.
3. App auf Emulator oder Gerät starten.
